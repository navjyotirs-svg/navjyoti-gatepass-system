# UI / UX

> **CRITICAL RULE:** For all UI design, screen generation, and design system tasks, you MUST take help of the connected **Stitch MCP Server** using the available Stitch tools.

Expected screens. (Only document them during Phase 0; do not implement yet).

1. **Visitor Entry Page:** Landing page with the visitor form (Name, Mobile, Company, Purpose).
2. **Photo Capture Step:** Camera interface to capture a live photo of the visitor.
3. **Approval Pending Screen:** Awaiting approval status screen.
4. **Gate Pass Screen:** The final approved digital pass with Navjyoti logo, details, photo, and QR code.
5. **Simple Admin Login:** Secure login for reception/admin.
6. **Pending Requests Screen:** Admin view of requests waiting for action.
7. **Approved Requests Screen:** Log of historically approved passes.
8. **Employee Management Screen:** Simple admin screen to add/edit/disable employees in the dropdown.

## Guidelines
- Keep navigation minimal.
- The visitor should not need an account.
- Admin functionality should be protected.
- Visitor workflow should require as few taps as possible.
