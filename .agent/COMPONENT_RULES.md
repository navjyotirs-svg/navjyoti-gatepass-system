# Component Rules

Likely reusable components (do not create during Phase 0).

- **NavjyotiLogo:** Renders the official branding logo consistently.
- **PageContainer:** Wrapper for consistent max-width and padding.
- **VisitorForm:** The primary input form for new requests.
- **EmployeeSelector:** Dropdown/combobox fetching from the employees table.
- **PhotoCapture:** Encapsulates the HTML5 camera/webcam API and outputs an image blob/URL.
- **ApprovalStatus:** Displays the current state of a request (Pending, Approved, Rejected).
- **GatePassCard:** The final digital pass UI.
- **QRCode:** Renders the pass number as a scannable QR.
- **StatusBadge:** Small visual indicator combining color and text.
- **PrimaryButton:** Main call to action button.
- **FormInput:** Reusable input fields with label and error state handling.
- **Modal:** For dialogs, confirmations, or displaying the gate pass.
