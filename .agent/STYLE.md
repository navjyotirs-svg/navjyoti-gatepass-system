# Visual Design Philosophy

> **CRITICAL RULE:** For all UI design, design variants, and design system tasks, you MUST take help of the connected **Stitch MCP Server** using the available Stitch tools.

**Target Look:** Professional corporate visitor-pass system

## Characteristics
- Clean
- Modern
- Minimal
- Premium
- Trustworthy
- Easy for security/reception
- Mobile-first visitor experience

**Branding:** Use Navjyoti branding. (The existing Navjyoti logo supplied for this project must be treated as the official branding reference. Do not redesign or replace it.)

## Anti-Patterns (Do NOT use)
- Excessive gradients
- Gaming-style UI
- Glassmorphism everywhere
- Excessive animations

## Design System

**Typography hierarchy:** Clean, modern sans-serif. Distinct headings vs body text.  
**Spacing system:** Predictable padding and margins, avoiding cramped layouts.  
**Border radius:** Subtle rounded corners for a modern, friendly but professional feel.  
**Card design:** Clean cards with subtle shadows for elevation.  
**Form styling:** Clear labels, visible focus states, simple inputs with good touch targets.  
**Buttons:** Prominent primary actions, clear secondary actions. Minimum 44x44px touch targets on mobile.  
**Status badges:** Distinctly shaped badges with clear text.  
**Icons:** Minimalist and universally understood.  
**Mobile behavior:** Forms must be highly usable on mobile screens, avoiding horizontal scroll and ensuring the camera UI works well.  
**Desktop behavior:** Cleanly centered, maximum width constraints to avoid stretched UI.

## Status Communication
Statuses should use **both color and text**. Never communicate status using color alone.
- **Pending:** E.g., Orange/Yellow with "Pending" text.
- **Approved:** E.g., Green with "Approved" text.
- **Rejected:** E.g., Red with "Rejected" text.
