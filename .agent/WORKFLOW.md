# Development Workflow

For every future phase, agents must follow this exact workflow:

1. Read agent documentation.
2. Inspect current implementation.
3. Identify affected files.
4. Understand dependencies.
5. Create implementation plan.
6. Make focused changes only.
7. Run lint/type-check/build.
8. Test affected user flow.
9. Check responsive behavior.
10. Check for regressions.
11. Update documentation.
12. Provide implementation report.
